# Telegram-ассистент

Эта папка — рабочее пространство для управления моим Telegram через Claude Code.
Запускайте `claude` отсюда: подключится MCP-сервер `telegram` (см. `.mcp.json`),
а права из `.claude/settings.json` будут спрашивать подтверждение перед каждой отправкой.
