# Персональный AI-ассистент в Telegram

Личный помощник: вы пишете ему в Telegram обычным текстом, он отвечает с помощью
GPT, Claude или локальной модели, помнит разговор и следит за расходами.
Отвечает только вам — всем остальным доступ закрыт.

Что готово сейчас и что будет дальше: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Установка на Windows (один раз)

1. Скачайте проект с GitHub (зелёная кнопка **Code → Download ZIP**) и распакуйте,
   например в `C:\pai`.
2. Дважды щёлкните **`install.bat`**. Он сам установит Python и всё нужное
   (первый раз — несколько минут), затем откроет файл `.env` в Блокноте.
3. Впишите в `.env` три строки и сохраните:
   * `BOT_TOKEN=` — токен бота от [@BotFather](https://t.me/BotFather);
   * `ALLOWED_TELEGRAM_IDS=` — ваш Telegram ID (узнать: [@userinfobot](https://t.me/userinfobot));
   * `OPENAI_API_KEY=` — ключ с [platform.openai.com/api-keys](https://platform.openai.com/api-keys).

   Файл `.env` остаётся только на вашем компьютере и в git не попадает. Никому его не пересылайте.

## Запуск

Дважды щёлкните **`start.bat`**. Появится окно с надписью «бот … запущен» — откройте бота
в Telegram и напишите ему. Пока окно открыто, бот работает; закроете окно — бот остановится.

Если вместо запуска видите «Ошибка настройки: …» — в сообщении написано, какую строку `.env`
исправить. Ключи и токены в сообщениях об ошибках не показываются.

## Как пользоваться

* Просто пишите — вопросы, задачи, черновики. Бот помнит текущий разговор.
* **🆕 Новый диалог** — начать новую тему (старый разговор сохраняется в истории).
* **🤖 Модель** — выбрать модель. С ключом Claude (`ANTHROPIC_API_KEY` в `.env`) по умолчанию
  отвечает Claude Opus 5.5; без него — GPT-6 Luna. Также доступны Claude Sonnet 5.5 и Haiku 5.5,
  GPT-6.1 Terra и Sol, локальная модель через Ollama (`OLLAMA_BASE_URL`).
* **⚙️ Настройки** — стиль ответов (коротко / обычно / подробно) и личные инструкции,
  например «Обращайся на ты, я маркетолог».
* **📊 Статистика** — сколько потрачено за месяц и сегодня, по моделям.
* **🎙 Голос** — отправьте голосовое (или аудио, кружочек) — ассистент распознает речь (русский и
  украинский), покажет, что услышал, и ответит голосом с текстом в подписи. В «🎙 Голос» —
  когда отвечать голосом, выбор голоса, скорость, манера речи и «🔊 Пример».
* **🧠 Память** — что ассистент запомнил о вас: предпочтения, факты, проекты, договорённости,
  как вы любите выполнять задачи, и прошлые обсуждения. Записи можно исправить или удалить,
  найти, выгрузить в файл, очистить. Там же — полное удаление всех ваших данных.
  Попросить запомнить: «запомни, что…» или `/remember текст`; забыть — «забудь, что…».

* **📎 Файлы, фото, видео** — просто пришлите, команды не нужны. Можно с подписью («найди ошибку»,
  «сверь с оплатами»), а можно сначала файлы, потом голосом или текстом объяснить задачу — бот
  поймёт, что это одно задание, и позже вспомнит прошлые файлы («сравни с предыдущим»).
  * Фото и скриншоты: прочитать текст, найти ошибку, разобрать чек, таблицу, график, интерфейс.
    Фото без сжатия — отправьте «как файл».
  * Документы: PDF (и сканы), Word (.docx), Excel (.xlsx), PowerPoint (.pptx), CSV, TXT, JSON,
    XML, ZIP. Большие документы читаются по частям. Бот может прислать результат файлом —
    таблицу Excel, отчёт Word, CSV.
  * Видео и аудиофайлы: что происходит, кто что говорит, расшифровка, итоги, нужный момент.
  * После нескольких файлов бот пишет, что получил, что прочитал, а что не удалось, и в конце
    сложной задачи — насколько уверен.
  * Ограничения: файл до 20 МБ (так Telegram отдаёт файлы ботам); старые .doc/.xls, HEIC, RAR/7z
    и программы не принимаются; файлы хранятся сутки, извлечённый текст — с разговором.
* **⏰ Напоминания** — скажите или напишите: «Напомни мне завтра в 10:00 позвонить врачу»,
  «Напомни через 2 часа проверить оплату», «Напоминай каждый понедельник в 9:00 проверить отчёты».
  Если время непонятно («в пятницу напомни про встречу»), бот спросит, во сколько. После создания
  приходит карточка с кнопками «Изменить» и «Удалить». Само напоминание приходит с кнопками
  «Готово» и «Отложить» (15 мин, 1 час, завтра). Напоминания приходят, даже если вы не открываете
  бот, и не теряются после перезапуска. Команды: `/reminders` — список, `/add_reminder` — добавить,
  `/delete_reminder 5` — удалить №5, `/timezone Europe/Kyiv` — часовой пояс (по умолчанию Киев).
* **🔔 Инициатива** — `/proactive_on` включает (по умолчанию выключено) короткие сообщения от
  ассистента: спросить, как идёт задача, о договорённости или незаконченном проекте. Пишет только
  когда есть конкретный повод из памяти, не повторяет тему 14 дней, молчит в тихие часы, если вы
  недавно писали или не ответили на два прошлых. Частота (раз в 3 дня / раз в день / до 3 раз в день), тихие часы
  и пояс — в «⚙️ Настройки». Выключить — `/proactive_off`.

## Контроль обучения сотрудников (рабочая группа)

Бот принимает записи разговоров сотрудников в рабочей группе, собирает статистику и напоминает
о записях. Он **контролёр и организатор, а не наставник**: записи не слушает, советов по продажам
не даёт, вопросы сотрудников о работе с клиентами пересылает вам.

**Подключение (один раз):**
1. В @BotFather: `/mybots` → ваш бот → **Bot Settings → Group Privacy → Turn off**.
   Без этого бот не увидит сообщения в группе. Другой вариант — сделать бота админом группы.
   После смены настройки удалите бота из группы и добавьте снова.
2. Добавьте бота в рабочую группу и напишите там **/bind** (от своего аккаунта).
3. Сотрудники присылают запись сразу после работы с клиентом с подписью
   `Имя | Клиент | Результат`. Результат — ✅ закрыл / 🔄 перенос (на когда) / ❌ отказ /
   📵 не дозвонился; можно словами: «закрыл», «перенос на пятницу 15:00», «отказ», «недозвон».
   Без подписи бот попросит её добавить. Человек попадает в список сотрудников после первой
   подписанной записи.
4. Необязательно: сотрудник может один раз нажать **Start** у бота в личке — тогда напоминание
   о переносе и вопрос «что случилось?» придут ему лично (Telegram не разрешает ботам писать
   первыми). Без Start всё работает через упоминание в группе.

Список сотрудников бот собирает сам: каждый, кто написал в группе, вступил в неё (если бот —
админ) — в списке; вышел — убран. Telegram не даёт ботам список участников, поэтому того, кто
ещё ни разу не писал, добавьте ответом `/add` на его сообщение или `/add Имя` после его первого
сообщения. Убранный командой /remove автоматически не возвращается.

**Ваши команды (в личке с ботом):** /today, /week, /employee Имя, /staff, /add Имя, /remove Имя,
/off Имя 15.11-20.11, /schedule, /announce текст. Оценка записи — ответьте на неё в группе,
например «Оценка 7/10, работай над возражениями». **Сотрудникам:** /my, /tips.

**Расписание** (меняется командой /schedule): работа 10:00–19:00 пн–сб. Проверка в 13:00: если
от сотрудника нет ни одной записи 2 рабочих дня подряд (выходные и отпуск не считаются), бот
один раз упоминает его в группе; одна запись за два дня — норма. Личка через 60 минут без ответа
(если нажимал Start), отчёт в 19:30, недельный — вс 20:00. Все тексты и время —
в `config/training.toml`.

**Ваши личные данные изолированы:** модуль группы не читает память, задачи, переписку и
напоминания вашего ассистента и не использует ИИ. В группу и сотрудникам уходят только готовые
тексты из настроек, личная статистика сотрудника ему самому и ваш текст из /announce.

## Голос бесплатно (без OpenAI)

По умолчанию голос работает через OpenAI (точнее и быстрее). Бесплатный вариант на вашем компьютере:
откройте командную строку в папке проекта, выполните `uv sync --extra local-voice` и добавьте в `.env`:
`STT_PROVIDER=local` (распознавание faster-whisper, при первом запуске скачает модель ≈ 0.5 ГБ) и
`TTS_PROVIDER=edge` (бесплатная озвучка Microsoft Edge). Локальное распознавание медленнее
(≈ 1 с на секунду речи без видеокарты) и чуть хуже на украинском. Озвучку edge-tts в облачной среде
разработки проверить не удалось — проверьте у себя.

## Проверка компьютера и резервные копии

* **`doctor.bat`** — показывает процессор, память, видеокарту и проверяет настройки
  (ключи не показывает). По нему видно, потянет ли компьютер локальные модели.
* **`backup.bat`** — резервная копия базы в папку `backups\`. Бот и сам делает копию при запуске
  и раз в сутки, хранит 14 последних.

## Расходы

Telegram бесплатный. Платите только провайдеру модели по факту:

| Модель | Цена за 1M токенов (вход / выход) | Примерно за одно сообщение |
|---|---|---|
| Claude Haiku 5.5 | $0.10 / $0.50 | ≈ $0.0001 |
| Claude Sonnet 5.5 | $2 / $10 | ≈ $0.002–0.006 |
| Claude Opus 5.5 | $4 / $20 | ≈ $0.005–0.015 |
| GPT-6 Luna | $0.10 / $0.50 | ≈ $0.0001 (живой замер) |
| GPT-6.1 Terra | $1 / $5 | ≈ $0.001 |
| GPT-6.1 Sol | $2 / $10 | ≈ $0.002–0.005 |

Голос через OpenAI: распознавание ≈ $0.003 за минуту, озвучка ≈ $0.015 за минуту
(голосовой ответ на 20 секунд ≈ $0.005). Живой замер: два полных голосовых обмена — $0.012.

Память работает в фоне на дешёвой модели (Claude Haiku или GPT-6 Luna): ≈ $0.0002 за 10 сообщений.

Месячный лимит задаётся в `.env`: `MONTHLY_BUDGET_USD=10`. При достижении бот перестаёт
обращаться к платным моделям и сообщает об этом. Дополнительно поставьте лимит в кабинете
OpenAI (Settings → Limits). Аварийное отключение: `PAID_APIS_DISABLED=1`.

## Для разработчика

```bash
uv sync --extra dev
uv run pytest -q
uv run ruff check src tests
```

Тесты не тратят денег: модель подменяется (`FunctionModel` pydantic-ai), Telegram —
локальным фейковым сервером. База — временная SQLite.

Добавить модель: блок `[[model]]` в `config/models.toml`. Изменить поведение ассистента:
`config/assistant.md`. Сменить базу на PostgreSQL: `DATABASE_URL=postgresql+asyncpg://…`
(и `uv sync --extra postgres`).
