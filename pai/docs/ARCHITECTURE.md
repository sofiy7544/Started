# Этап 2. Архитектура и технический план

## Схема

```
 Telegram (iPhone) ── текст / (голос, файлы — этапы 5–6) / кнопки
        │
        ▼
 AccessMiddleware — белый список ALLOWED_TELEGRAM_IDS (до любой обработки)
 DedupMiddleware  — каждый update_id один раз
        │
        ▼
 Обработчики aiogram: меню и команды │ переписка
        │
        ▼
 Assistant (services/assistant.py) — не зависит от Telegram
   • лимит частоты, предохранитель после серии ошибок
   • разговор: последние MAX_HISTORY_TURNS обменов в пределах MAX_HISTORY_CHARS
   • инструкции: config/assistant.md + стиль + личные инструкции + дата
   • BudgetGuard: резерв верхней оценки → вызов → учёт фактической стоимости
        │
        ▼
 PydanticAIEngine (llm/engine.py) — единый интерфейс к моделям
   каталог config/models.toml: OpenAI │ Anthropic │ Ollama │ новые провайдеры
   ошибки провайдеров → понятные категории (FailureKind)
        │
        ▼
 SQLite (позже PostgreSQL) через SQLAlchemy 2 + миграции Alembic
```

## Структура

```
pai/
├── config/models.toml      каталог моделей (добавить модель — без правки кода)
├── config/assistant.md     системные инструкции ассистента
├── src/pai/
│   ├── __main__.py         запуск, проверки при старте
│   ├── config.py           настройки из .env (pydantic-settings)
│   ├── logging_setup.py    логи без текста исключений и переписки
│   ├── db/                 модели SQLAlchemy, миграции Alembic
│   ├── llm/                catalog.py (модели, цены), engine.py (вызовы), checks.py (проверка ключей)
│   ├── services/           assistant.py, budget.py, limits.py, stats.py
│   └── bot/                app.py (middlewares), session.py (прокси), texts.py, handlers/
├── tests/                  pytest: настоящий pydantic-ai с подставной моделью, фейковый Telegram
├── install.bat, start.bat  установка и запуск на Windows
└── .env.example            образец настроек
```

## База данных

| Таблица | Назначение |
|---|---|
| users | Telegram ID, выбранная модель, личные инструкции, стиль ответов |
| conversations | разговоры; «🆕 Новый диалог» закрывает текущий |
| turns | обмены: тексты (архив) + сообщения pydantic-ai (для контекста), токены, стоимость |
| usage_records | расходы: модель, токены, стоимость, confirmed=false — оценка при неизвестном исходе |
| audit_events | журнал действий без текста сообщений (смена модели, отказ в доступе, ошибки API) |
| processed_updates | защита от повторной обработки апдейтов |

Этап 4 добавит таблицы памяти (факты, проекты, договорённости) отдельной миграцией.

## Безопасность (реализовано)

* Белый список Telegram ID; пустой список — бот не запускается. Посторонний не доходит до
  обработчиков и не тратит деньги; отказ — не чаще раза в час, попытка — в журнал.
* Секреты только в `.env` (в `.gitignore`); ошибки настройки не показывают значений.
* Логи: только типы исключений и места в коде (SafeFormatter), без текста переписки.
* Нет выполнения команд и доступа к файлам — инструменты появятся на этапе 7 с уровнями риска
  и обязательным подтверждением опасных действий.

## Расходы (реализовано)

* Месячный лимит `MONTHLY_BUDGET_USD` (USD, календарный месяц UTC), резерв до вызова атомарный —
  параллельные запросы не превысят лимит; потолок на запрос `PER_REQUEST_COST_LIMIT_USD`.
* Стоимость: из pydantic-ai/genai-prices; неизвестная модель — по максимальному тарифу.
* Таймаут/отмена/некорректный ответ — учёт по верхней оценке × число попыток.
* `PAID_APIS_DISABLED=1` — аварийное отключение платных моделей (локальная Ollama работает).
