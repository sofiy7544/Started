# Virtual Companion Telegram — текстовый MVP

Telegram-бот с оригинальным виртуальным персонажем Мирой. Ответы генерирует
Claude API. Персонаж честно обозначен как AI, помнит важное о каждом пользователе
отдельно, а расходы ограничены месячным бюджетом.

Архитектура, схема БД и планы: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Что умеет

* Естественная переписка на русском. Характер задаётся в [persona/mira.toml](persona/mira.toml).
* `/start` — приветствие, пометка «AI-персонаж, не реальный человек», подтверждение 18+.
* `/help`, `/privacy`, `/reset` (новый разговор, память сохраняется), `/memory`
  (что запомнено), `/forget` (стереть память или удалить все данные, с подтверждением).
* Память: история диалога, резюме прошлых разговоров, факты (как обращаться,
  интересы, предпочтения, незавершённые темы). Устаревшие факты заменяются.
  Всё хранится в PostgreSQL и переживает перезапуск.
* Индикатор «печатает…», разбиение длинных ответов, защита от повторной обработки
  апдейтов, лимиты частоты, понятные сообщения при сбоях API.

## 1. Что нужно подготовить (только вы)

1. **Токен бота.** В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` →
   скопируйте токен вида `123456789:AA...`.
2. **Ключ Claude API.** [console.anthropic.com](https://console.anthropic.com) → API Keys →
   Create Key. Пополните баланс. В разделе Limits можно задать лимит расходов
   и на стороне Anthropic — это вторая страховка к лимиту в боте.
3. **Где хранить секреты.** Только в файле `.env` на сервере (он в `.gitignore`) или в
   секретах хостинга. Не вставляйте токены в код, в git и в чаты.

```bash
cd companion
cp .env.example .env
chmod 600 .env
nano .env        # BOT_TOKEN, ANTHROPIC_API_KEY, POSTGRES_PASSWORD
```

## 2. Запуск через Docker (рекомендуется)

```bash
cd companion
docker compose up -d --build
docker compose logs -f bot          # ждите строку «bot @ваш_бот started»
```

Остановка: `docker compose down`. Данные лежат в volume `pgdata` и при этом
сохраняются. Удалить всё вместе с данными: `docker compose down -v`.

Резервная копия БД:
```bash
mkdir -p backups
docker compose exec -T db pg_dump -U companion companion | gzip > backups/$(date +%F).sql.gz
```

## 3. Локальный запуск без Docker

Нужны Python 3.12+ и PostgreSQL 14+.

```bash
cd companion
python3 -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
createdb companion                    # или через psql: CREATE DATABASE companion;
set -a && . ./.env && set +a          # подгрузить переменные; добавьте в .env DATABASE_URL=postgresql://...
python -m companion
```

Миграции применяются автоматически при старте.

## 4. Тесты

Тесты не обращаются к настоящим Telegram и Claude: модель подменяется, а Bot API и
Anthropic API заменяются локальными HTTP-серверами. Нужен PostgreSQL.

```bash
cd companion
# один раз: отдельная пустая база только для тестов
psql -c "CREATE USER companion WITH PASSWORD 'companion' CREATEDB" && createdb -O companion companion_test
export TEST_DATABASE_URL=postgresql://companion:companion@localhost:5432/companion_test
python -m pytest -q
ruff check src tests
```

⚠️ Тесты очищают базу `TEST_DATABASE_URL` (DROP SCHEMA). Не направляйте их на рабочую БД.

## 5. Проверка в Telegram

1. Найдите бота по имени и нажмите **Start**. Должно прийти приветствие с пометкой,
   что это AI-персонаж, и кнопка «Мне есть 18, начнём».
2. Напишите «привет» до нажатия кнопки — бот попросит подтвердить возраст.
3. Нажмите кнопку и поговорите: «Привет, меня зовут Саша», «я люблю джаз»,
   «у меня завтра собеседование». Ответы должны быть короткими и живыми, без
   приветствия в каждом сообщении.
4. Спросите «ты настоящая?» — она должна честно сказать, что она AI.
5. После 15–20 обменов сообщениями откройте `/memory`: там должны появиться имя,
   интересы и тема про собеседование.
6. `/reset` — разговор начнётся заново, а `/memory` останется.
7. Перезапустите бота (`docker compose restart bot`) и спросите «что ты обо мне помнишь?».
8. `/forget` → «Память и историю» → «Да, удалить» → `/memory` покажет пустую память.
9. Отправьте стикер — бот ответит, что пока понимает только текст.
10. Проверьте расходы: `docker compose exec db psql -U companion -c "select date_trunc('day', created_at) d, count(*), sum(cost_usd) from api_usage group by 1 order by 1"`.

## 6. Расходы и лимиты

Цены Claude Haiku 5.5: $0.10 за 1M входных и $0.50 за 1M выходных токенов.

| Сценарий | Оценка |
|---|---|
| Одно сообщение (≈2–6 тыс. токенов контекста, до 1000 на ответ) | ≈ $0.0004–0.0011 |
| Фоновое сжатие памяти (примерно раз в 8 обменов) | ≈ $0.0005 |
| 1 000 сообщений | ≈ $0.5–1 |
| Бюджет по умолчанию $20/мес | ≈ 20–40 тыс. сообщений |

С `CHAT_MODEL=claude-sonnet-5-5` ответы качественнее, а стоимость примерно в 20 раз выше
($2 / $10 за 1M токенов).

Встроенные ограничители (настраиваются в `.env`, см. `.env.example`):
`ANTHROPIC_MONTHLY_BUDGET_USD=20` — жёсткий месячный лимит (проверка до вызова);
после 80% бюджета бот переходит на `MEMORY_MODEL`; `PAID_APIS_DISABLED=1` —
аварийное отключение; `DAILY_MESSAGES_PER_USER=80`, `MESSAGES_PER_MINUTE=8`;
`MAX_REPLY_TOKENS=1000`; история в запросе ограничена 40 сообщениями и 16 000 символов;
`LLM_MAX_RETRIES=2` повтора только для временных ошибок; после 3 ошибок подряд
обращения к API приостанавливаются на 60 секунд, при неверном ключе — на 10 минут.

Хостинг: самый маленький VPS (1 vCPU, 1 ГБ RAM) обходится примерно в $5–6 в месяц.

## 7. Настройка персонажа

Отредактируйте [persona/mira.toml](persona/mira.toml): имя, возраст (не меньше 18),
биография, черты характера, вкусы, правила речи, примеры интонации и приветствие.
Перезапустите бота. Правила честности (AI-персонаж, не реальный человек, без выдуманных
событий) и безопасности заданы в коде (`CORE_RULES` в `src/companion/persona.py`) и
файлом персонажа не отключаются. Другой файл подключается через `PERSONA_PATH`.

## 8. Частые проблемы

| Симптом | Причина |
|---|---|
| `Ошибка конфигурации: Не заданы переменные окружения` | Не заполнен `.env` |
| `Telegram отклонил BOT_TOKEN` | Неверный токен — получите заново у @BotFather |
| Бот отвечает «Сервис сейчас недоступен» | Неверный `ANTHROPIC_API_KEY`, кончился баланс или неверное имя модели; в логах будет `llm configuration error` |
| «Сервис временно приостановлен» | Достигнут `ANTHROPIC_MONTHLY_BUDGET_USD` или включён `PAID_APIS_DISABLED` |
| «Связь барахлит» | Временная перегрузка API; бот сам повторил запрос `LLM_MAX_RETRIES` раз |
| Бот молчит в группе | Так задумано: бот работает только в личных сообщениях |
